## 1. Цель работы
Разместить разработанное веб-приложение Nail Salon API на хостинге, обеспечить доступ по HTTPS с действующим SSL/TLS-сертификатом и задокументировать результат.

## 2. Сведения о приложении
Приложение разработано на Java 17 и Spring Boot. Оно предоставляет REST API для предметной области маникюрного салона, документацию Swagger/OpenAPI и авторизацию с помощью JWT. В проекте подготовлены Dockerfile, production-профиль Spring Boot и конфигурация для подключения к PostgreSQL через переменные окружения.
